# 🚚 Automação de Triagem Logística (Support Triage Automation)

Projeto desenvolvido para otimizar o fluxo de chamados de suporte técnico em operações de logística, telemetria e rastreamento de frota.

## ⚙️ Tecnologias Utilizadas
* Python 3
* Pandas (Manipulação de Dados)
* Matplotlib (Geração de Dashboards/Gráficos)
* SQLite (Banco de Dados Relacional)

## 🚀 Funcionalidades
1. Processamento de extrações `.csv` do sistema de tickets.
2. Categorização automática de incidentes críticos (GPS, Hardware, Autenticação).
3. Armazenamento seguro dos dados sanitizados em banco de dados SQLite.
4. Geração automática de gráficos de barras para análise gerencial.
